Help: ask a question without GitHub

The "Still stuck?" aside at the foot of /help. "Ask a question" no longer opens GitHub (most people have no GitHub account). It opens a short form in the same aside: one text box, Send and Cancel. The question is emailed to admin@zontakllc.com with reply-to set to the person's address. The page never shows the person's name or email (the service worker keeps /help across sign-out). Signed-out visitors get a sign-in link instead of the form.
