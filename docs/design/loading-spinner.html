Loading: one calm spinner, only on slow waits

When a save, invoice, export or send is still open after 300 ms, the button you pressed shows this small spinner; a faster answer shows nothing, so nothing flickers. While it works the button is off and says what it is doing ("Saving…", "Creating…"). On Log time the spinner sits in the round disc instead of the clock icon; the words stay "Logged 2:00" for their moment, then "Log time". With reduced motion the spinner stands still. A button's own icon (Download, Mail) stays until the spinner takes its place, so a fast export never makes it blink.

For the owner to accept (a change from the spec): the entry edit Save is not wired. Its save() closes the form (setEditing(false)) before the server is asked, so the Save button is gone while the save runs and has nothing to show. Help's Send is the second e2e target instead of entry-edit Save. The first e2e target is Today's Log time.

Offline: when the device knows it is offline, Log time stores the entry on the device and never asks the server, so the spinner never shows. When the connection drops during a save, the request fails with a network error (mutations use networkMode: "always", so they are never paused), the spinner goes, and the entry is queued on the device. The spinner does not stay on while an entry waits in the queue.
