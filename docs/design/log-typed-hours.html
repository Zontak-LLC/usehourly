Log time card: typed hours are never lost

One button, one job. With a time typed, the amber button says exactly what it saves ("Log 2:00"; after "+ 30 min" it says "Log 2:30"). Its screen-reader name stays "Log time", the same as "Logged 2:00" today. Start timer stays a quiet ghost line at the foot; while a time is typed it is off, with one neutral muted line that says why. Log the time (or clear the box) and Start timer works again. No amber or red on the reason line.
